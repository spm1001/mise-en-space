## For Claudes to come

**The envelope you test through may not be the envelope you ship — check which artefact your probe actually reaches before believing either a red or a green.** mise's MCP server spawns with `--project ${CLAUDE_PLUGIN_ROOT}`, so it always runs the *published* plugin under `~/.claude/plugins/cache/`, never the working tree. Two consequences that cost this session real time. First, "smoke through the MCP envelope, then publish" is **circular by construction**, and no session restart breaks the loop — the only envelope available runs the code you were trying to test before shipping it. CLAUDE.md had told readers to smoke in a fresh session, which cannot work, and that false row survived until someone actually asked whether reloading helped. The fix is a harness that drives the working tree directly (`scripts/smoke_stdio.py`): same FastMCP stack, same tool wrapper, same JSON on the wire, just not spawned by Claude Code. Second, and more generally: **a long-running session is pinned to whatever it loaded at start**, so an old session runs superseded code while its Claude reasons from a current working tree — a doc/runtime divergence with no tell.

**And the companion, learnt ninety seconds after writing that harness: a probe's *display* is part of the probe.** Mine truncated output at 400 characters and printed only the `error` field. Google's 404 URL alone eats ~350, so the teaching text these cases existed to check sat just past the cut — and the one case that genuinely *succeeded* rendered as a blank line, because success has no `error` field. It reported `3/3 passed` while the screen showed what looked like three failures, and I spent a round convinced my new code was broken. This is the familiar truncation trap running in reverse: the usual danger is a truncated view read as a complete answer, but a truncated view read as a **null**, and a null read as a **failure**, is just as available and feels even more like diligence. When a probe surprises you, check the instrument's *rendering* before you doubt the subject.
