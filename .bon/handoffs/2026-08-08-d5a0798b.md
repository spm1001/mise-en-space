## For Claudes to come

**A manifest key is a contract with every consumer that keys on its presence, not just the one you added it for.** Tonight `tabs` was widened to single-tab sheet manifests so `?gid=` could resolve — and `do(create, source=)`, which detects multi-tab deposits by `manifest.get("tabs")`, silently switched routes for single-tab deposits. The delta happened to be benign (same import engine underneath, tab name now preserved), but nothing would have said so if it weren't. Before widening WHERE a manifest key is written, grep for everywhere it is READ — `grep -rn '\"tabs\"\|get(\"tabs\")'` cost one minute at close and was the only thing standing between "shipped improvement" and "unpinned behaviour change". The general form: presence-keyed readers make every write-side widening a routing decision somewhere else.

**The pointer pattern: resolve a caller's targeting against the deposit, and non-resolution becomes a feature.** All five URL decorations resolve with zero extra API calls because mise already downloads everything the ids name — the design cost was recording three small maps in the manifest at write time (doc structure with line offsets, tab sheet_ids, slide index). Two durable sub-lessons: mise GENERATES content.md, so it can know which line anything lands on — offsets are free at write time and unrecoverable afterwards; and a pointer that fails to resolve against data-in-hand is staleness DETECTION (deleted tab, resolved comment), information no API surface offers directly. Google's own guarantees set the reporting register: immutable ids (tabs) warrant a firm "stale", read-only-but-unguaranteed ids (headings) warrant a gentle one.

**Alignment guards beat alignment cleverness when mapping API structure to rendered text.** Heading→line mapping works by order+count+level agreement per tab, with the extractor's injected-title quirk handled as one explicit case — and on ANY mismatch it keeps ids and text but omits line numbers (the checkbox-oracle discipline: never a wrong number). The watched-red control for this was a NORMAL paragraph whose literal text was "## fake" — the exact input that would have corrupted a cleverer matcher.
