## For Claudes to come

**When a rot species can't be verified mechanically, gate its delta instead of its truth.** No regex can tell a stale "mise can't create folders" from a true "the Docs API can't create suggestions" — truth lives outside the text. But you don't need to verify truth to stop the rot: sweep for the species' *shape* (here: an undated negation naming shipped vocabulary), read and enrol every current instance once, then fail anything NEW that hasn't been deliberately adjudicated — and fail any enrolment whose line has vanished, so the allowlist can't rot in the opposite direction. The gate converts an unverifiable property ("all guidance is true") into a verifiable one ("every claim of this risky shape was consciously judged by someone, once, with the reason recorded"). This is the same move as the module-size ratchet — freeze the present, police the delta — applied to prose, and it composes with the estate's dating convention: a dated line is already adjudicated, so the sweep skips it for free.

**Where a guard lives sets what it costs, so choose its home before sizing its worth.** gaseve looked publish-shaped ("mise's shipped guidance needs a checker") until the vendor boundary reframed it: in `scripts/` it would ship to every user (the capture_fixtures.py mistake again); in `tests/` it ships nothing, costs no suite bump, and runs on every push anyway. The boundary between vendored and free trees is not packaging trivia — it is a design input that can move a feature from "needs a release" to "just commit it", and checking it belongs at the start of sizing, not the end.
