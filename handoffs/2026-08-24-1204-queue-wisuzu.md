**An `except MiseError` around a bare `client.post_json`/`get_json` is dead code.** The sync client raises httpx types; conversion to MiseError happens only inside `@with_retry`. When a new tools module calls the client raw, either wrap the call in `@with_retry` (which also buys the retry) or catch httpx — and pin the error path with the REAL exception type, because a test that injects MiseError passes forever against a path the wire can never reach.
