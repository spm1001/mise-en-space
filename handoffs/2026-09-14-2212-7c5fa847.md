### Reflection

The test seam moved and ten tests in `tests/unit/test_search.py` patched the old name. That module's own autouse fixture deletes `MISE_TOKEN_PATH` (so normal-mode source defaults can be pinned), which means an unpatched adapter call there reads the developer's real token — and one did: `test_unfiltered_default_window_needs_no_query` returned `20 == 1` from Sameer's live diary before I saw why. Read-only, no harm, and the conftest's own docstring predicts exactly this; the fixture docstring now names the two seams. The generalisable bit: when you move the function a default path calls, grep the tests for patches at the OLD name before running them on a box with a live token — a green from a mis-seamed patch is the unearned kind, and a red may have cost a live call.

Two ratchets bit in one run (module size, description budget), and both did their job: the code went to a sibling module and the description got shorter instead of the numbers going up. The description budget is the surface with no room — docs.py and SKILL.md carry the full story, the description carries twelve words.
