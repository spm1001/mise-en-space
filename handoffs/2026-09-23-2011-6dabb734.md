**Pre-register the tripwire, not just the endpoint.** The Tier 1 pre-registration said "if mise is cheaper everywhere, suspect the B counter first", and that single sentence caught a scorer that had already produced a confident headline. The audit then worked because it was exhaustive rather than targeted: enumerate every non-MCP tool result across every run and classify it, rather than re-checking the cases you suspected. Two general facts fell out: a transcript token counter must price image and document blocks at the vision rate (w×h/750 on Opus 5/5.5, calibrated against the model's own per-turn usage deltas), never tokenise their base64; and Claude Code spills oversized MCP results to a file and hands the model a pointer, so an "inline" server gets deposit behaviour from the client — to-completion cost has to follow content wherever it lands. And a guard that has never excluded anything is untested: the answer-write exclusion never fired once in 60 runs because it matched only a relative path.
