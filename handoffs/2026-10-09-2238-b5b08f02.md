## For Claudes to come

A quote-stripping reader and a quoting writer live in the same codebase, and the obvious implementation of the writer uses the reader's output. In mise, `fetch` strips each message's quoted history so Claude reads every message once; a `reply_draft` that quoted "the last message" from that extraction would quote only the newest text and sever the chain for everyone downstream — the same severed chain mise's bare, unquoted replies have produced since February. When building the write side of anything the read side normalises, start from the raw artefact, not from the cleaned view.
